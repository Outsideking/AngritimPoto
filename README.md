ความสามารถของอัลกอริทึม (Auto-run Text-Based Image + OCR)

1. สร้างภาพจากข้อความหลายส่วน (Multi-Section Text Rendering)

สามารถรับ input เป็น list ของข้อความหลายบรรทัด

รองรับหลาย section เช่น part1, part2, …

วางข้อความในตำแหน่งกำหนดด้วย offset ที่ปรับได้



2. วาด bounding box รอบข้อความ

คำนวณขนาดของข้อความอัตโนมัติ

วาดกรอบรอบข้อความแต่ละ section

ใช้สำหรับการแยก OCR หรือ visual reference



3. ปรับ layout อัตโนมัติ

แต่ละ section มีการจัดวางอย่างเป็นระเบียบ

ปรับตำแหน่งข้อความโดยไม่ชนกัน

รองรับหลาย section บน canvas เดียว



4. รองรับการใช้งานอัตโนมัติ (Auto-run)

ไม่ต้องใช้ GUI

รันโปรแกรมแล้วสร้างภาพ + ทำ OCR ได้ทันที

เหมาะกับการทำ batch หรือ integration กับระบบอื่น



5. OCR แยกส่วนข้อความอัตโนมัติ

อ่านข้อความจากภาพโดยใช้ bounding box ของแต่ละ section

ส่งคืน dictionary ของแต่ละ part (part1, part2, …)

รองรับหลาย section พร้อมกัน



6. บันทึกภาพและเอกสาร

บันทึกไฟล์ PNG (combined_image_with_boxes.png)

รองรับนำไปใช้งานต่อได้ทันที



7. โค้ดปรับแต่งง่าย

สามารถเพิ่ม section, ขนาด canvas, สี หรือฟอนต์ได้ง่าย

รองรับการปรับ offset หรือ scaling ของข้อความ
